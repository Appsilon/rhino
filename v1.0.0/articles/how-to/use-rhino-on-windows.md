# How-to: Use Rhino on Windows

You can use JavaScript & Sass tools on Windows 10. You will need to
[install Node.js and
yarn](https://go.appsilon.com/rhino-system-dependencies) and enable
[Developer
Mode](https://docs.microsoft.com/en-us/windows/apps/get-started/enable-your-device-for-development#active-developer-mode).
