# How-to: Use shiny.fluent with Rhino

[`shiny.fluent` package](https://appsilon.github.io/shiny.fluent/)
brings the beautiful look of Microsoft Fluent UI to the world of Shiny.
You can use it to build your Rhino applications - it works out of the
box.

Check out [this
tutorial](https://appsilon.github.io/shiny.fluent/articles/st-shiny-fluent-and-rhino.html)
to learn how you can combine those two packages.
